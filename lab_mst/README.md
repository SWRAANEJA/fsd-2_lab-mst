# Post Box with Character Counter (React + Vite)

## Run
1. Install Node.js (v18+): https://nodejs.org
2. In this folder:
   npm install
   npm run dev
3. Open the URL shown (usually http://localhost:5173)

## Features
- Controlled textarea (value + onChange)
- Live counter, e.g. 45 / 100
- Red "Limit exceeded" message when text is over 100 characters
- "Post" button disabled when text is empty (or only spaces) or over the limit
